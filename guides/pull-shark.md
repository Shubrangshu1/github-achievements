# Pull Shark Achievement Guide

The **Pull Shark** badge recognizes developers who regularly create and merge pull requests.

## Tiers
- **Bronze**: 2 merged pull requests
- **Silver**: 16 merged pull requests
- **Gold**: 128 merged pull requests

## Tips for Earning
- Maintain regular feature branching workflows.
- Keep pull requests small, focused, and well-documented.
- Clean up merged branches to maintain repository hygiene.
