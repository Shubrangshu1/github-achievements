# GitHub Achievements Guide

A complete reference guide to earning and leveling up badges on your GitHub profile.

## Badges Overview
- **Pull Shark**: Opened pull requests that were merged.
- **Pair Extraordinaire**: Co-authored a commit merged into a pull request.
- **Quickdraw**: Closed an issue or PR within 5 minutes.
- **YOLO**: Merged a PR without code review.
- **Galaxy Brain**: Answer marked as accepted in GitHub Discussions.
- **Starstruck**: Repository reached 16+ stars.
- **Public Sponsor**: Sponsoring open source contributors.
