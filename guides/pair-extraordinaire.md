# Pair Extraordinaire Achievement Guide

The **Pair Extraordinaire** badge celebrates collaborative software development through co-authored commits.

## Tiers
- **Bronze**: 1 merged pull request with a co-author
- **Silver**: 10 merged pull requests with a co-author
- **Gold**: 24 merged pull requests with a co-author

## How to Co-Author
Add this trailer to the end of any git commit message:
```text
Co-authored-by: Name <username@users.noreply.github.com>
```
